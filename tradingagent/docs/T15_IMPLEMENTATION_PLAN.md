在用户指定根目录继续自主实施，使用已安装tradingagent Conda Python；依赖由用户管理。不提交、推送、部署或使用真实资金/收费模型。离线部分完成，真实24小时未验收；完整证据见ACCEPTANCE_REPORT.md。

## 设计决定

核心Journal/会话/预算/成交/复盘继续使用现有schema7并永久保留。公共行情原始采样和分钟聚合属于可清理的辅助存储；新增独立SQLite sidecar，避免以清理任务触及已有审计事实。sidecar保存有限行情投影、UTC时间、模式和来源哈希；不含账户/凭据/用户文本，不作为当前余额或交易事实。

保留默认7天1秒采样、90天已收盘分钟K线；固定批次清理，复盘固定证据已在核心Journal完整冻结。被显式pin的辅助记录不能删除。归档故障显示降级并停止该写入worker，行情缓存与硬纪律继续；核心审计故障仍按既有机制停止建议。备份使用SQLite在线备份而非复制活动WAL文件；恢复保留审计链和未知费用。

可选用户数据流只产生REST对账提示。单槽提示、重连退避与RetryAfter、不根据私流消息修改余额/成交；权限拒绝停止私流并保留REST。显式启动开关要求账户只读开关，默认不启用私流。进程恢复后账户缓存从空开始，已有持仓和会话不构成新鲜发布证据。

运行诊断使用固定事件代码/计数和有限日志；不把外部异常、请求URL、签名或原始HTTP/WS内容写入日志。日志轮转、sidecar清理和真实前台退出分别测试。首版不自动安装Windows后台服务。
