# JEV 多会话工作台

## 用户流程与范围

一个入口：左侧会话列表，右侧新建向导或当前会话工作区。向导按用途（JEV 建议 / JEV 自动模拟操盘）、USDT 永续币种与历史、0–100 整数风格、资金与策略完成配置。最后创建并启动，不再跨三个页面设置。同屏可暂停、恢复、查行情、决策、钱包和逐笔档案。

多个 JEV 会话可以同时后台运行。切换显示不暂停后台；每个会话独立币种、风格版本、策略与虚拟钱包。建议只保存模型结果，不提交成交。自动操盘继续使用通用执行器和严格交易档案。常规 Agent 暂缓，方案见 REGULAR_AGENT_SCRIPT_PLAN.md。

## 隔离与保留

复用单会话内核：每个新任务单独 SQLite 和 ApplicationServices/runtime；根目录任务索引仅保存用途、名称、会话身份和创建参数。保留原根库已关闭 BTC 与当前 OGN 会话，不充值、改风格或清零。关闭会话仍能查看档案。每个任务使用同一原 model_budget_database；真实模型累计/未知预留/单次限额不重置、不提高，无期限保持。

任务 ID 和数据库名由服务生成，不接受客户端文件路径。创建使用持久幂等 ID，重复或失败重试不能创建第二钱包或改变资金。创建失败保留记录，可在该会话恢复；重启统一恢复暂停，不能自动重新收费。会话 start/pause 携带会话/账户版本，固定指向 task_id，任何选择切换不能改变命令目标。

## 验证边界

离线验证两个任务同时运行、切换不影响、建议不成交、共享预算路径、创建重试和版本冲突、原会话导入与档案归属。浏览器仅查看原真实钱包或离线新任务，不为 UI 测试启用收费。真实多会话持续收费性能与长稳另行观察。
