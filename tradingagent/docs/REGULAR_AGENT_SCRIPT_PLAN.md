# 常规 Agent 定时脚本方案（暂缓）

2026-10-08 用户明确：当前只开发 JEV，多会话后台并行主要用于 JEV。

未来常规 Agent 的预设流程：把近期行情和交易情况交给 LLM，LLM 通过 codewriting 编写定时分析脚本；由脚本持续监测，并在必要时再请求 LLM。目的为减少高频模型费用及推理延迟。Flash 与 JEV 保持并列，常规 Agent 不进入 JEV 的关键决策路径。

本阶段不实现脚本生成、执行环境、调度或常规 Agent 后台。未来开发前再确认脚本权限、可用数据、输出接口和失败恢复；生成代码不能未经隔离直接获得交易或本机权限。工作台常规 Agent 入口仅标注“规划中”。
