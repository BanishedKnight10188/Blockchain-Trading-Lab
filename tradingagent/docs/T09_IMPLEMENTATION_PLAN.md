## 选择与边界

采用后台单进程采样、不可变最新帧和只读查询；不用浏览器请求触发行情或账户网络读取。
默认启动不连接外网。公共行情和账户读取分别显式启用；凭据只在装配入口读取环境，启动缺配置明确失败。
离线注入按来源显示Fake/Replay，不能冒充Binance。真实WS与账户验收仍独立记录。

页面沿用STYLE_CONTROL的浅色工作台与字体。页首导航到总览/会话设置；总览以价格、时间和数据状态为主，左右对照行情与账户，底部明确建议尚未装配和JEV未定义。
保留风格设置确认流程；不会让行情刷新重置尚未提交的滑杆选择。无数据不画虚构走势，不展示零收益。

## 顺序与验收

1. 查询测试先行：Decimal字符串、无账号/凭据、确认余额与未知成本、5s/60s时效、来源隔离、未来数据拒绝、无数据不可评估。
2. 查询服务读取最新帧；SSE每客户端只取最新版本，重连只恢复当前帧，旧进程ID不冒充历史回放。浏览器断开不停止后台。
3. 后台采样与同步测试先行：一个market stream消费者、独立账户任务、故障隔离、取消清理、无Web请求时仍推进、存储故障不反复写。
4. Web测试先行：只读GET保护、CSRF/Origin/Host既有检查、没有交易路由、只用本地静态资源、错误不反射敏感数据。
5. 装配与启动测试：工程配置严格校验，按显式开关构建Direct适配器，未授权模式不读取凭据；无安装/收费模型/资金写入。
6. 总览实现与浏览器检查，窄测试、独立审查、最终回归/离线wheel及台账。
