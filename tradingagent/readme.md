先从已有的、先进的trading agent 开始学习condor相关框架
我对即将开发的trading agent 的定义为：
  1.提供建议而非自动交易
  2.24/7持续监控市场，并在不同场景下路由不同的api，以实现成本控制
  3.区分human-made 选择和agent-made 选择 且记录交易的时间点并生成复盘，历史复盘不一定是生成即不变的，也可以一段时间call   back
  4.绝对的纪律性以及可选择的交易风格(稳健/激进)，风格应该在会话创建时设定，也可以在工作过程中切换
  5.服务于短线交易，持仓时使用JEV给出建议(hold/sell/buy)以便实时的操作。
  6.账户的安全性是第一位。


目前我希望在借鉴已有agent的基础上开发，主要选择是binance agent OS和condor，condor框架更加先进更加完整，但是高度利用hummingbot生态。
